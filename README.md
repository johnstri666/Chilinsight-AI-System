# Chilinsight-AI-System
-----------------------------
Johnstrilians, 2026


This project focuses on the application of EfficientNet-B4 and XAI (Grad-CAM) in developing a neural network model for multiclass classification of diseases in chili plants.

The classes are divided into:
1. Healthy Fruit
2. Healthy Leaves
3. Cercospora Leaf Spot
4. Yellow Virus
5. Anthracnose



The use of CompVi Explainable AI (Grad-CAM) helps in understanding the model’s performance in making decisions through visual heatmaps based on the processed input images.
